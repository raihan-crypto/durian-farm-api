# Paket Dokumen Sistem Informasi Manajemen Perkebunan Durian

Paket ini berisi delapan dokumen awal:
- PRD.md
- SRS.md
- ARCHITECTURE.md
- DATABASE.md
- API_SPECIFICATION.md
- BUSINESS_RULES.md
- UI_UX_GUIDELINES.md
- TESTING.md

Dokumen disusun dari kebutuhan dan informasi proyek yang telah disampaikan. Bagian yang belum dapat dipastikan diberi label draft, usulan, atau perlu dikonfirmasi. Khusus database dan API, verifikasi terhadap schema dan route aktual wajib dilakukan sebelum menjadikan dokumen sebagai kontrak implementasi.

Jangan gunakan dokumen ini sebagai alasan untuk melakukan migrasi destruktif. Perubahan database harus ditinjau dan diuji pada database non-production terlebih dahulu.
